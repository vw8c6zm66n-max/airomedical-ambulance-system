# Design and Development of an Air Ambulance Patient Transfer Management System (AAPTMS)

## Project Overview
The Air Ambulance Patient Transfer Management System (AAPTMS) is a centralized digital solution designed to optimize aeromedical logistics and improve critical care transit workflows. In high-stakes emergency operations, manual coordination and fragmented communication can create operational bottlenecks. This project bridges the gap between aviation logistics and medical triaging by providing a real-time, data-driven management framework.

Built using the MERN stack (MongoDB, Express.js, React.js, Node.js), the platform automates vital processes to significantly reduce dispatch latency, helping healthcare providers maximize asset utilization during the critical "Golden Hour."

## Core Features
* **Live Fleet Telemetry:** Real-time asset tracking and positioning using mapping APIs for accurate ETA coordination.
* **Automated Intake & Triage:** Algorithmic prioritization of emergency retrieval requests based on patient clinical severity.
* **Dynamic Resource Allocation:** Intelligent matching of critical patients with appropriate transport assets and destination specialized care units.
* **Seamless Data Continuity:** Centralized digital record management ensuring uninterrupted patient information handovers between sending facilities, air crews, and receiving ICUs.

## Tech Stack
* **Frontend:** React.js, HTML5, CSS3 (Modern, high-contrast dark theme dashboard)
* **Backend:** Node.js, Express.js (RESTful API Server)
* **Database:** MongoDB Atlas (Cloud-managed persistence layer)
